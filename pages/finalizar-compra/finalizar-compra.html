Informações importantes

Pagamento aprovado? Se você estiver logado, redirecionaremos para Meus Pedidos. Se não estiver, exibiremos o código do seu pedido na tela para acompanhar em “Acompanhar pedido”.

Dica de segurança: prefira cartão virtual. Não armazenamos dados do seu cartão.

Força, foco e fé — vista a mensagem, treine com propósito.

Escaneie o QR Code acima com o aplicativo do seu banco para concluir o pagamento.

Após o pagamento, aguarde a confirmação. Você será redirecionado automaticamente para a tela de pedidos caso esteja logado. Caso contrário, irá aparecer o código do pedido, que você usará para obter as informações do pedido.
